# DLM Desktop 1.3.11（r222）日本語マニュアル

**1.3.11/r222：HTTP応答のBrotli自動展開を停止し、CVE-2026-111497への緩和策を適用しました。gzip・deflateの処理と既存機能を保持します。古いDLMを終了し、正式ZIP全体を新しい空フォルダーへ展開して起動してください。埋込みブラウザーには安定版WebView2 Runtime156.0.4314.42以降が必要です。**

**1.3.11/r222 mitigates CVE-2026-111497 by disabling automatic HTTP Brotli decoding while retaining gzip, deflate and existing features. Close the old DLM and extract the full official ZIP into a new empty folder. Embedded browsing still requires stable WebView2 Runtime156.0.4314.42 or later.**


[マニュアル入口](../MANUAL.md) · [English](en.md) · [README](../README.md)

Windows x64版 1.3.11（r222）が対象です。確認日：2026年10月26日（日本時間）。画面ラベルは配布記録に対応する最新ソース `537f6f52f513eb3a2d329bcf829aaedddf4e2335` のXAML・表示用プロパティ・日英ローカライズ処理に基づきます。コード表記は日本語設定での実際のラベルです。公式サイト内のログイン・購入・ダウンロード操作は、各サイトの画面に従ってください。

## 基本操作：まずはこれだけ

この4つの手順で、保存先を決めて、対応作品をダウンロードし、ライブラリから開けます。最初は画像やPDFなど、[通常配信](#ordinary)に対応する作品で進めると操作を確認しやすくなります。

<a id="start"></a>
### 1. アプリを起動する

1. [最新版の配布ページ](https://github.com/Ertelun/dlm-desktop/releases/tag/v1.3.11)からWindows x64 ZIPを取得します。
2. 以前のDLM Desktopを終了し、ZIP全体を新しい空のフォルダへ展開します。
3. `DoujinLibraryManagerDesktop.exe` を起動します。隣にある `app` フォルダも必要です。

.NETは同梱されています。埋め込みブラウザの利用には安定版Microsoft Edge WebView2 Runtime156.0.4314.42以降が必要です。日本語以外で起動した場合は、[表示と言語](#language)で変更できます。

左側の移動先は次の4つです。先頭の○は未選択、●は現在の画面を示します。

| 表示例 | 用途 |
|---|---|
| `○ ライブラリ` | 保存済みの作品を探し、開く |
| `○ 続きから` | 閲覧・起動・新規登録の候補から再開する |
| `○ ダウンロード` | 公式サービスのページでダウンロードを開始する |
| `○ 設定` | 保存先、言語、バックアップなどを管理する |

<a id="library"></a>
### 2. ライブラリを指定する

1. 初回の案内で `ライブラリを選択して設定` を押します。
2. 作品を保存・管理するフォルダを選択します。新しく使う保存先、またはDLMの既存ライブラリを指定します。
3. 読み込みが終わるまで待ちます。最初のフォルダがダウンロード先にも設定されます。

`後で` を選んだ場合は、ライブラリ画面上部の `ライブラリを選択` から設定します。設定済みの場合、このボタンはフォルダの追加になります。

複数の保存先を登録したときは、★の付いた1フォルダが新規ダウンロード先です。[フォルダの追加と保存先変更](#roots)で確認できます。普通のファイルを入れた任意のフォルダを指定するだけで、すべてが新規作品として登録されるわけではありません。

<a id="download"></a>
### 3. 作品をダウンロードする

1. 左側の `○ ダウンロード` を開きます。
2. 上部で利用するサービスを選びます。たとえば `DLsite`、`DMM / FANZA`、`itch.io`、`BOOTH` です。
3. 表示された公式サイトでログインし、購入済み作品などのページを開きます。
4. **公式サイト側のダウンロード操作**を行います。サイト内のボタン文言は配信元や作品によって異なります。
5. 右側の `DLセンター` でダウンロード・検証・展開・登録の状態を確認します。右側が細いバーになっている場合は、`↓` アイコンから同じ画面を開けます。
6. 保存・登録処理が終わったらライブラリへ移動し、作品が表示されることを確認します。必要なら `再読み込み` を押します。

転送が100%でも、検証・展開・登録が続く場合があります。**ライブラリに作品が表示され、開けることまで確認してください。** GOGは[受付確定](#gog)が必要です。会員制サービスは[投稿ごとの操作](#membership)、DLsiteの分割配信は[分割ファイルの操作](#multipart)に従います。

<a id="view"></a>
### 4. ダウンロードした作品を開く

1. 左側のライブラリへ戻ります。
2. 作品名を検索するか、作品カードを探します。
3. 画像・PDF・動画・音声などの対応作品では `閲覧` を押します。閲覧履歴がある作品では `再開` と表示されます。
4. ビューアの `目次` で項目を選ぶか、`← 前へ`／`次へ →` で移動します。
5. `閉じる` でライブラリへ戻ります。保存された閲覧位置は次回の再開に利用されます。

作品に応じて表示される操作は異なります。ゲームは[起動／インストール](#games)、制作素材は[素材の確認](#assets)を使用します。詳しい内容はカードの `詳細` から確認できます。

## 各機能の操作

<a id="providers"></a>
### 配信元に合わせてダウンロードする

<a id="ordinary"></a>
#### DLsite・DMM/FANZA・itch.io・BOOTH・Gumroadの通常配信

ダウンロード画面でサービスを選び、公式ページでログインと保存開始を行います。Gumroadでは `Gumroad` を選び、公式ライブラリやコンテンツ画面から対象ファイルを保存します。対応アーカイブ・単体ファイルは検証後に登録されます。

| 配信元 | この版の保存方法 |
|---|---|
| DLsite | 対応する通常アーカイブ。分割配信は[別手順](#multipart) |
| DMM/FANZA | 対応する通常ダウンロード。公式プレイヤー専用などは公式手段を利用 |
| itch.io・BOOTH | 対応アーカイブと対応する単体ファイル |
| Gumroad | 公式ライブラリ／コンテンツ画面からユーザーが開始した対応ファイル |

対応範囲は [Provider Capabilities](../PROVIDER_CAPABILITIES.md) を参照してください。ファイル形式を認識できても、すべての配信方式や作品を処理できるわけではありません。

<a id="multipart"></a>
#### DLsiteの分割ファイルを保存する

1. `DLsite` を選び、対象作品の公式ダウンロードページを開きます。
2. `part1.exe` と必要な後続partを、同じ作品の配信ファイルとしてすべてダウンロードします。
3. `part1.exe` の保存確認が必要な場合は `ブラウザの保存確認` を開き、ブラウザ側の状態を確認します。
4. 各ファイルの保存・登録が終わったことを `DLセンター` で確認します。
5. ライブラリの作品から `実フォルダ` を開き、一式を確認します。

原本のファイル名を保って同じ作品へまとめます。DLMは分割ファイルの結合やインストーラーの自動実行を行いません。展開・インストールが必要な場合は、その作品の公式説明に従ってください。

<a id="gog"></a>
#### GOGのインストーラー一式を1作品として登録する

1. `GOG` を選び、公式アカウント／ライブラリページへログインします。
2. 対象ゲームのOffline Backup Game Installerの必要ファイルをすべて保存します。`.exe` と必要な `.bin` などを揃えます。
3. ダウンロード中・確認中の処理が終わるまで待ちます。
4. `GOG受付を確定して登録` が操作できる状態になったら押します。右側のツールを縮めているときも、上部の受付確定案内から操作できます。
5. 登録完了後、ライブラリで作品を確認します。

**ファイルの保存だけでは作品登録は終わりません。受付確定まで行ってください。** DLMはインストーラーを自動実行・自動展開しません。登録後の[ゲーム操作](#games)は別の操作です。

<a id="membership"></a>
#### Fantia・pixivFANBOX・Patreon・Ci-enの投稿を保存する

1. 該当するサービスボタンを選び、公式サイトへログインします。
2. 保存したい**投稿の詳細ページ**を開きます。
3. その投稿の公式ダウンロード操作で、対応する画像・添付ファイルを保存します。
4. 同じ投稿の追加ファイルも保存します。投稿に結び付いたファイルは同じ作品へまとめられます。
5. `DLセンター` とライブラリで保存・登録の結果を確認します。

この版では投稿タイトルなどの手入力や、DLM側の受付開始・終了操作は不要です。投稿一覧を自動巡回して一括保存する機能ではありません。Ci-en内の対応するDLsite作品・予告作品リンクはDLsite画面へ引き継ぎます。

<a id="browser"></a>
### ブラウザを移動する・外部ブラウザを開く

| 右側の操作 | 用途 |
|---|---|
| `戻る`／`進む` | 表示履歴を移動 |
| `再読み込み` | 現在のページを再読み込み |
| `外部ブラウザ` | 現在の許可された対象をWindowsの既定ブラウザへ引き継ぐ |
| `ブラウザの保存確認` | ブラウザ標準のダウンロード確認画面を開く |
| `DLセンター` | 保存・処理の履歴と進行状況を開く |
| `保存先変更` | 設定画面で★の保存先を変更する案内を開く |

右側の `›` でツールを縮め、縮小時の `‹` で展開できます。細いバーの各アイコンにマウスを置くと用途を確認できます。サービスボタンにマウスを置いたときのメニューから、そのサービスのホームやライブラリなどへ戻れます。

サービスの既定ページを変えるには、設定の `ブラウザの既定ページ` で対象サービスのURLを編集し、その行の `保存` を押します。`既定値に戻す` で初期値へ戻せます。ダウンロード画面に出すサービスは各行の `非表示` で隠し、隠した後は `表示` で戻せます。対象サービスのHTTPS URLだけを保存でき、非表示にしても保存済み作品は削除されません。

埋め込みブラウザでログインできない場合は、公式の別ログイン方式や `外部ブラウザ` を利用します。外部ブラウザのログイン状態はDLMにコピーされません。**外部ブラウザから保存した任意のフォルダを、この版で新規作品として登録する独立した取り込み操作はありません。** 既存作品の詳細に表示される `ダウンロード済みフォルダを選択` は安全確認の補助で、[新規登録とは異なります](#troubleshooting)。

<a id="progress"></a>
### 進捗を確認する・キャンセルする

`DLセンター` はダウンロード・展開・登録の進行状況を表示します。`キャンセル` が表示され、操作できる行ではその処理をキャンセルできます。キャンセル可能な段階は処理によって異なります。

総サイズが不明な転送では、`ダウンロード中（受信済み 123.4 MiB）` のように受信容量を表示します。同時転送の表示は約150ミリ秒ごとに更新します。配信元の準備や転送後の検証・展開には待ち時間が生じるため、受信容量と処理段階を併せて確認してください。

`履歴をクリア` は操作可能なときに履歴を消します。作品ファイルの削除には使いません。転送後の検証や展開には時間がかかるため、転送率と登録結果を区別して確認してください。

Activity Centerが開いている場合は `状態を再読込` で現在状態を更新し、`作品詳細へ` などで対応する作品へ移動できます。外部の公式ブラウザ・配信アプリで行う転送の進捗や完了を、DLMの進捗から判断することはできません。

<a id="redownload"></a>
### 既存作品の更新を調べる・再ダウンロードする

1. 対象作品の `詳細` を開きます。
2. `アップデート確認` で公式商品ページの更新日と保存済みダウンロード日を確認します。取得できる情報により判断できない場合があります。
3. 再取得する場合は `再ダウンロード` を押し、表示される確認を読みます。
4. 開いた公式商品ページで、ユーザー自身がダウンロードを開始します。
5. 検証と登録の結果を確認します。

既存作品の再取得では元の保存場所を再確認して置換処理を行います。新規作品用の★保存先へその作品を移す操作ではありません。重複・移動・保存先の未接続などを検出した場合は、自動置換を停止します。

<a id="roots"></a>
### ライブラリフォルダを追加する・保存先を変える・移す

設定画面の `ライブラリフォルダ` を使用します。

| やりたいこと | 手順 |
|---|---|
| 複数のライブラリを横断表示 | `ライブラリフォルダを追加` でフォルダを登録 |
| 新規ダウンロード先を変更 | 対象行の `★ ダウンロード先にする` を押す |
| 登録だけ解除 | 対象行の `一覧から外す` を押す。作品ファイルは削除しない |
| フォルダを別の場所へ移す | 利用可能な行の `移動支援…` から空の移動先を選び、コピー・検証・切替の確認を進める |
| 未接続の保存先を探し直す | 未接続行の `再接続…` で候補を選び、作品の照合結果を確認する |
| 中断した移動を続ける | `未完了の移動を再開 / 確定…` を使用 |
| 未完了の移動記録を解除 | `未完了の移動記録を解除…` を使用。記録の解除で元データやコピーは削除されない |

ライブラリフォルダは最大32件登録できます。新規保存先は登録済みフォルダの1件だけです。★のフォルダが未接続でも、別フォルダへ自動切替しません。移動支援はコピー・ファイル検証・安全スナップショットの後に登録先を切り替え、元フォルダは自動削除しません。

<a id="watch"></a>
### 指定フォルダの新しい対応ファイルを取り込む

1. 設定画面の `監視フォルダ` で `監視フォルダを追加` を押します。
2. 監視したいローカルフォルダを選びます。
3. `自動受付を有効にする` を有効にします。
4. すぐ確認したい場合は `今すぐ確認` を押します。
5. 監視をやめる場合は対象行の `解除` を押します。

監視フォルダは最大4件です。指定フォルダの直下を5秒間隔で確認し、対応するアーカイブ・PDF・画像・動画・音声・3Dモデルを取込経路へ渡します。サブフォルダを再帰監視しません。コピー中のファイルはサイズと更新時刻が安定してから受付し、同じ内容の重複登録を抑止します。元ファイルは自動削除しません。

<a id="search"></a>
### 作品を検索する・条件を組み合わせる

1. ライブラリ画面で検索欄に入力します。`Ctrl+F` で検索欄へ移動できます。
2. 作者・カテゴリ・サイトのフィルターを開き、必要な項目を複数選択します。
3. お気に入り、コレクション、履歴、関係の条件を必要に応じて組み合わせます。
4. 条件を外すときは有効条件のチップを押すか、`すべて解除` を押します。

検索には表示タイトル・元タイトル・別言語タイトル、作者名、商品ID、配信元、カテゴリ、形式、コレクションなどの保存済み情報を使います。同じ作者フィルター内などの複数選択はOR、種類の違うフィルター同士はANDです。たとえば「作者AまたはB」かつ「CGまたはマンガ」のように絞れます。

`作者をすべて解除`、`カテゴリをすべて解除`、`サイトをすべて解除` はその種類だけを解除します。`すべて解除` は検索・絞り込みを解除し、並び順は保持します。

<a id="display"></a>
### 並び順・カード密度・グループ表示を変える

ライブラリの並び順は `タイトル ↑`、`作者 ↑`、`カテゴリ ↑`、`サイト`、`最近開いた順` から選べます。表示は `標準グリッド`、`コンパクトグリッド`、`コンパクトリスト` から選択します。`Ctrl+Shift+D` でも密度を切り替えられます。

グループ表示は `管理` を開き、`作者別`、`グループ化なし`、`カテゴリ別`、`サイト別`、`状態別` から選びます。

<a id="saved-views"></a>
### よく使う検索条件を保存して呼び出す

1. ライブラリで検索・フィルター・並び順を設定します。
2. `管理` → `表示条件を保存・再利用…` を開きます。`Ctrl+Shift+V` でも開けます。
3. 表示条件名を入力し、`現在の条件を保存` を押します。
4. 後で一覧から選び、`選択した条件を適用` を押して呼び出します。
5. `名前変更`／`削除` で保存条件を管理します。

ここでの削除は保存条件の削除です。作品ファイルには影響しません。

<a id="collections"></a>
### お気に入り・コレクションで作品を整理する

カード上の星でお気に入りを切り替えられます。カードのコレクションアイコン、または `詳細` → `コレクションを編集` で編集画面を開き、`お気に入り` やコレクション所属を変更して `保存` を押します。

コレクション自体の作成・名称変更・削除は `管理` → `コレクション管理` で行います。名前を入力して `追加`、対象を選んで `名称変更`／`削除` を使用します。コレクションはDLM上の分類で、実フォルダを移動する操作ではありません。

<a id="bulk"></a>
### 複数作品をまとめて操作する・隠す・削除する

1. 作品カード／行の選択チェックを使い、対象を選びます。
2. 選択メニューの `▶` を開きます。
3. `表示中をすべて選択`／`選択解除` で対象を調整します。
4. `★ お気に入りにする`、`☆ お気に入り解除`、`コレクションへ追加`、`コレクションから解除` などを選びます。コレクション操作では対象コレクションも選択します。

`作品を非表示` は通常のライブラリ表示から隠します。`管理` → `非表示にした作品` で確認し、`作品を再表示` で戻せます。非表示は作品ファイルを削除しません。

**`作品を削除` は作品フォルダ内のファイルを完全削除する操作です。ごみ箱に移す操作ではありません。** 確認画面で対象を確認してください。[ユーザー状態のバックアップ](#backup)には作品本体が含まれないため、作品本体を残したい場合は別にコピーを用意します。

<a id="metadata"></a>
### 表示タイトル・作者・カテゴリ・代表画像を整える

1. `管理` → `作品情報整備` を開きます。
2. 対象作品を選択します。
3. `表示タイトルを変更`、`作者 / サークル表示を変更`、`表示カテゴリを変更` のうち変更したい項目を有効にし、値を入力します。
4. 1作品だけを選択している場合は `代表画像を変更` → `作品内画像を選択` で、その作品内の画像を指定できます。
5. `変更をプレビューして適用` で対象と変更内容を確認し、適用します。

有効にしたフィールドを空欄のまま適用すると、その項目のユーザー上書きを解除します。代表画像は `原本へ戻す`、全上書きは `選択作品の上書きをすべて解除` で戻せます。表示用情報の変更で、作品ファイル・元の配信元情報・フォルダ名を変更する操作ではありません。表示カテゴリを変えても、ビューア／ゲーム判定の元カテゴリは変わりません。

<a id="creators"></a>
### 同じ作者の表記をまとめる・1作品だけ修正する

1. ライブラリで基準にする作品を選択し、`管理` → `作者名をまとめる・修正` を開きます。
2. 表示したい作者名を既存候補から選ぶか入力します。
3. 同じ元作者名の作品をまとめる範囲、または `この作品だけ作者名を変える` を選びます。
4. 変更後の表示と影響範囲を確認し、`この内容で適用` を押します。
5. 解除するときは `同じ作者名のまとめ設定を解除`／`この作品だけの設定を解除` を使います。

作者表示・検索・フィルター・作者別グループに反映されます。作品ファイルや配信元の情報を編集する操作ではありません。

<a id="stacks"></a>
### 同じ作品の複数エントリを表示上でまとめる

1. 一括選択で対象作品を選び、`選択を同一作品グループ化` を押します。
2. 確認画面の対象を確認して保存します。Action Centerの候補から `Stackにまとめる` を使う方法もあります。
3. ライブラリのグループ展開ボタンで各エントリを表示し、開きたい作品を選びます。
4. 作品詳細から `この作品を代表にする`、`この作品をStackから外す`、`Stackを解除` で管理します。

同一作品グループは表示上の整理です。各エントリの配信元・商品ID・ファイル・保存先は独立したままです。Append／DLC関係の代わりには使いません。

<a id="relations"></a>
### ゲームのAppend／DLCを親作品に結び付ける

1. 対象ゲームの `詳細` → `追加作品/DLC 手動設定` を開きます。
2. `追加作品 として親作品へ紐づけ` または `DLC として親作品へ紐づけ` を選び、親作品を指定します。
3. `保存` で設定します。
4. 自動判定が不適切な場合は `独立作品として固定（自動判定を抑止）`、手動設定を解除したい場合は `手動設定を削除して自動判定に戻す` を選びます。

元metadataに明示された関係はこの画面で上書きしません。設定はDLMのローカル状態に保存されます。親カードの展開操作や詳細の関連作品から子作品へ移動できます。

<a id="continue"></a>
### 閲覧やゲームを続きから再開する

左側の続きから画面はContinue Hub 2.0を表示します。閲覧位置・成功したゲーム起動・ライブラリ登録時刻から候補を作り、新しい順に最大24件を表示します。候補の実行ボタンから対象作品を開きます。グループの代表ではなく、実際に利用したエントリが対象です。

`隠す` はその時点の候補を非表示にし、`表示候補をクリア` は現在の表示候補をまとめて隠します。`非表示を戻す` で戻せます。作品・閲覧位置・ゲームファイルは削除しません。新しい閲覧や起動があれば候補が再表示されます。

<a id="reader"></a>
### 画像・PDFを読む・目次とブックマークを使う

| 操作 | 使い方 |
|---|---|
| `目次` | 一覧でページ／メディアを選び、`選択項目へ移動`。一覧の項目をダブルクリックして移動することも可能 |
| `最初から` | 作品の先頭へ戻る。履歴やブックマークの削除ではない |
| `← 前へ`／`次へ →` | 前後のページ／メディアへ移動 |
| `単ページ`／`見開き` | 画像のレイアウトを変更 |
| `右→左 (RTL)`／`左→右 (LTR)` | 画像の読み方向を変更。矢印キーの進行方向にも反映 |
| `☆ ブックマーク` | 現在の画像ページのブックマークを切り替える |
| `前★`／`次★` | 前後のブックマークへ移動 |
| `画面に合わせる`／`1:1表示` | 表示サイズを切り替える |
| `全画面` | 全画面表示を切り替える |

PDFの内部ページには `← PDF前ページ`／`PDF次ページ →` も使えます。画像用レイアウトやブックマークは、対応するメディアのときだけ利用します。

`連続閲覧` と `前の作品`／`次の作品` は作品間の移動に使います。操作可能な対象があるときに利用できます。画像を自動で進めるにはスライド間隔を選び、`スライドショー開始` を押します。

`ランダム OFF` を切り替えると、次の作品への移動は現在のライブラリの絞り込み結果から、現在作品以外の閲覧可能な作品をランダムに選びます。前の作品への移動は通常のままです。

### 全画面で作品を削除して次へ進む（1.3.8以降）

全画面視聴中に `Shift+Delete` を押すと、現在表示している作品のフォルダーを完全削除する確認が出ます。初期選択はキャンセルです。**ごみ箱を使わず、作品本体を完全削除します。** 対象を確認してから実行してください。

成功後は同じ全画面で次の作品へ進みます。現在の絞り込みと表示順・ランダム設定に従います。表示順の末尾や対象がない場合はライブラリへ戻ります。キャンセル・失敗した場合は元の作品へ戻ります。

削除中は処理段階・削除済みファイル数・経過時間を表示します。`Esc` または `ライブラリに戻る` で閲覧を終了できます。確認済みの削除は戻った後も続行するため、削除の取り消しにはなりません。ファイル数やストレージによって、物理削除には時間がかかる場合があります。

<a id="media"></a>
### 動画・音声を再生する

対応メディアを開くと自動再生を試みます。`▶ 再生 / 再開`、`⏸ 一時停止`、`■ 停止`、シークバー、音量を使用できます。トラック／動画の終端で次の項目へ連続再生します。

| キー | 動画・音声での動作 |
|---|---|
| `Space`／`K` | 再生・一時停止 |
| `←`／`→`、`J`／`L`、`Ctrl+←`／`Ctrl+→` | それぞれ5秒・10秒・30秒戻す／進める |
| `↑`／`↓`、`M` | 音量を5%調整／ミュート切替 |
| `[`／`]`、`R` | 速度を0.25倍ずつ変更（0.50～2.00倍）／1.00倍へ戻す |
| `A`、`B`、`X` | リピート開始点／終了点／ABリピート解除 |
| `N`／`P` | 次／前の動画・音声トラック |

拡張子に対応していても、ファイルのコーデックなどによって再生できない場合があります。`既定アプリで開く` で外部の対応アプリへ渡せます。現在のメディアに合った操作一覧は `ヘルプ` で確認できます。

<a id="model3d"></a>
### 3Dモデルの視点・パーツ・テクスチャを確認する

1. 対応する3Dモデルをビューアで開きます。左ドラッグで回転、右ドラッグで移動、ホイール／中ドラッグでズームします。
2. `表示をリセット` や正面・背面などの視点ボタンで見やすい位置へ戻します。
3. `パーツ / テクスチャ` を開き、モデル上または一覧からパーツを選びます。
4. `ここへズーム`、`このパーツだけ`、`全パーツ表示` などで確認します。
5. `テクスチャを選ぶ →` から作品内の候補を選び、`このパーツに適用` で表示へ適用します。`別画像を選ぶ`／`元に戻す` も利用できます。
6. `↶ 元に戻す`／`↷ やり直す`、`現在状態を保存`、`選択した履歴を再適用` で表示状態を管理します。

表示状態と作品内テクスチャ割り当ての履歴は最大30件です。履歴を戻した後に新しい変更を行うと、先のやり直し履歴は破棄されます。購入したモデルや画像の原本は変更しません。専門的な編集は `専門ソフトで開く`、原本の確認は `作品フォルダ` を使います。

<a id="assets"></a>
### 制作素材を確認して専門ソフトへ渡す

素材作品ではカードに `素材を確認` が表示されます。詳細画面の `DLDで確認` でも軽量Inspectorを開けます。形式や基本情報を確認し、編集したい場合は `専門ソフトで開く`、原本を探す場合は `実フォルダを開く` を使用します。

DLM内の確認と、専門ソフトで行う編集は別です。すべての素材形式をDLM内で編集できるわけではありません。

<a id="games"></a>
### ゲームを起動する・インストールする・実行ファイルを選び直す

ゲームの状態に応じて `起動`、`起動ファイルを選択`、`インストール` などが表示されます。表示された操作を押し、必要な実行ファイルの選択・確認を行います。インストーラーを動かす場合は、その後のインストーラーの説明に従います。

自動判定が合わない場合は作品詳細から操作します。

| 詳細の操作 | 用途 |
|---|---|
| `起動として手動設定・EXE選択` | 作品フォルダ内のEXEを選び、起動作品として扱う |
| `インストールとして手動設定・EXE/MSI選択` | EXE／MSIを選び、インストール作品として扱う |
| `別のEXEで起動` | 別のEXEを選択する。開始できた選択は作品用に保存される |
| `自動判定へ戻す` | 手動分類と保存した起動先を解除する |

選択対象は作品フォルダ内の対応ファイルです。ダウンロード完了だけでインストール／起動は行いません。公式プレイヤー専用作品はその公式手段を使用します。

<a id="backup"></a>
### ユーザー状態をバックアップ・復元する

1. 設定画面のバックアップ／復元欄で `今すぐバックアップ…` を押します。
2. `.dlmbackup` の保存先を選び、含まれる情報の確認画面を読んで保存します。
3. 復元する場合は `バックアップから復元…` でファイルを選び、表示された確認を進めます。
4. 任意のタイミングで復旧点を作るには `安全スナップショットを作成`、未完了操作を確認するには `未完了操作を確認…` を使用します。

対象にはお気に入り・コレクション、保存条件、作者名補正、手動関係、同一作品グループ、作品情報の上書き、閲覧状態などが含まれます。**作品ファイル、ログイン認証情報、実行設定のバックアップではありません。** バックアップ自体は暗号化されません。

影響の大きいローカル状態変更では安全スナップショットが自動作成されます。最大5世代・合計512 MiBを目安に保持し、最新の有効復旧点を残します。作品本体を保護したい場合は別にファイルのバックアップを用意してください。

<a id="maintenance"></a>
### キャッシュ・保存サムネイルを削除する

設定のストレージ保守で対象を選び、確認画面に従います。

| 操作 | 対象 |
|---|---|
| `ブラウザキャッシュを削除` | ブラウザキャッシュ。Cookie・ログイン状態・LocalStorage・IndexedDBは保持 |
| `ダウンロードキャッシュを削除` | アプリが管理するダウンロードキャッシュ |
| `保存サムネイル削除` | 保存サムネイル。必要な場合は再生成・再取得する |

公式画像を補完したいときは `管理` → `公式サムネイルを確認・補完` を使います。保存済みの公式サムネイルを再取得せず、未取得作品の取得可能なものを確認します。

<a id="health"></a>
### ライブラリの問題・確認候補を調べる

`管理` → `ライブラリ診断` で到達性、表示情報、関係、空き容量の診断を行います。`再チェック` で診断を更新し、状態やカテゴリの条件で結果を絞ります。診断だけでは作品の移動・削除や情報の自動変更を行いません。

`管理` → `対応事項` では同一作品候補と作品情報の確認項目を調べます。`ライブラリで確認` で作品を確認し、`Stackにまとめる`／`作品情報を整備` で対応できます。`無視した項目も表示` で以前に無視した項目も確認します。候補が出ただけでファイルが統合・削除されることはありません。

<a id="language"></a>
### 日英の言語・表示テーマを変更する

設定 → `表示とアクセシビリティ` で操作します。

- `言語`：`システム言語に合わせる`、`日本語`、`英語` を選択します。開いているアプリ画面にも反映されます。
- `テーマ`：`システム設定に合わせる`、`ライト`、`ダーク` を選択します。Windowsの高コントラスト設定が優先されます。

言語変更は作品名・作者名を機械翻訳する設定ではありません。公式WebページやWindows標準のフォルダ選択画面は、それぞれの言語設定に従います。

<a id="troubleshooting"></a>
### 困ったとき：症状から確認する

| 症状 | 確認すること |
|---|---|
| 保存先を設定するよう求められる | [ライブラリを指定](#library)。★保存先が接続されているか[設定](#roots)で確認 |
| ブラウザが表示されない | 安定版WebView2 Runtime156.0.4314.42以降へ更新し、DLMを再起動してください。ZIP全体を展開して `app` をEXEの隣に置いているか確認 |
| ログインが拒否される | 公式の別ログイン方式や[外部ブラウザ](#browser)を使用。外部ブラウザのログインがDLMにも反映されるとは限らない |
| 転送100%なのに作品がない | [DLセンター](#progress)で検証・展開・登録を確認。GOGは[受付確定](#gog)が必要 |
| ZIPから展開した日本語の名前が文字化けする | 1.3.5以降で元ZIPから再展開。元ZIPがなければ作品詳細の[再ダウンロード](#redownload)で公式サイトから取得し直す。起動だけで既存の名前は修復されない |
| DLsiteのpart1.exeが待機する | [ブラウザの保存確認](#multipart)で保存完了を確認。必要な後続partもすべて取得 |
| 作品が見つからない | 検索・フィルターを解除し、[非表示作品](#bulk)と[保存先の接続](#roots)を確認して再読み込み |
| 外部ブラウザで保存したフォルダを登録したい | この版には任意フォルダの独立した新規登録操作がない。既存作品詳細のフォルダ選択は検証補助。対応するファイルの[Watch Folder](#watch)受付は別機能 |
| 動画・音声・モデルが開けない | 対応形式でも内容やコーデックにより失敗する場合がある。[既定アプリ／専門ソフト](#media)で開くか実フォルダを確認 |
| ゲームの起動先が違う | [詳細からEXEを選び直す](#games) |
| ★保存先が未接続 | [再接続](#roots)または登録済みの別フォルダを明示的に★にする |
| バックアップを復元しても作品本体が戻らない | ユーザー状態バックアップには本体が含まれない。[作品本体の別バックアップ](#backup)を確認 |

対応範囲は [Known Limitations](../KNOWN_LIMITATIONS.md) を参照してください。不具合報告は [Feedback](../FEEDBACK.md) の案内から行えます。
