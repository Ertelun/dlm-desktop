# DLM Desktop 1.3.22 / r233

## 日本語

- 設定 → ライブラリフォルダで「★ ダウンロード先にする」を押すと、コレクション一覧のある環境でアプリが終了する問題を修正しました。
- 切り替えは新規ダウンロードの保存先に適用されます。既存の作品は元のフォルダーに残ります。

DLMを終了し、Windows x64 ZIP全体を新しい空フォルダーに展開して起動してください。埋込みブラウザーには引き続き公式の安定版 WebView2 Runtime 157.0.4341.57 以降が必要です。配布物の確認には同ページの SHA256SUMS.txt を使用できます。

## English

- Fixed a crash when selecting **Set as download destination** under **Settings → Library folders** in installations with a saved collection catalog.
- The selected folder applies to new downloads. Existing works stay where they are.

Close DLM and extract the full Windows x64 ZIP into a new empty folder before launching. The embedded browser still requires the official stable WebView2 Runtime 157.0.4341.57 or later. Use SHA256SUMS.txt on this release page to verify the download.
