# 保存した作品を探す：検索と組み合わせフィルター

[English](#en) · [日本語マニュアル](../manual/ja.md#search)

「作者Aか作者Bのマンガを探したい」ときは、作者とカテゴリを組み合わせて絞り込めます。DLM Desktopの検索対象は、PC上のライブラリに登録した作品の保存済み情報です。

## 作品名や作者名から探す

1. ライブラリ画面で `Ctrl+F` を押して検索欄に移動します。
2. 作品名や作者名を入力します。表示タイトル・元タイトル・別言語タイトル、商品ID、配信元、カテゴリ、形式、コレクションなどの保存済み情報も検索に使われます。
3. 検索結果が多ければ、作者・カテゴリ・サイトのフィルターを追加します。

## 作者とカテゴリを組み合わせる

1. 作者フィルターで「作者A」と「作者B」を選びます。同じ種類のフィルターでは、どちらかに一致すれば対象になります（OR）。
2. カテゴリフィルターで「マンガ」を選びます。異なる種類のフィルターは両方の条件を満たす作品に絞ります（AND）。この例では「作者Aまたは作者B」かつ「マンガ」です。
3. 必要に応じてサイトやコレクションの条件も追加します。

## 見つからないとき

- **作品は登録済みですか？** ライブラリに作品があるか確認し、保存済みのタイトルや作者名の表記で検索し直します。検索範囲は登録済みの作品情報です。作品ファイルの本文や配信サイトのカタログは検索範囲外です。
- **条件を外すには？** 適用中の条件のチップを押すと、その条件を外せます。`作者をすべて解除` などは該当する種類だけを解除します。`すべて解除` は検索と絞り込みを解除し、並び順を保持します。

DLM DesktopはWindows x64向けです。ローカル利用は無料で、DLMアカウントは不要です。[最新の正式リリース](https://github.com/Ertelun/dlm-desktop/releases/latest) · [既知の制限](../KNOWN_LIMITATIONS.md)

# Find saved works with search and combined filters

[日本語](#ja) · [English manual](../manual/en.md#search)

If you want to find manga by either of two creators, combine the creator and category filters. DLM Desktop searches saved information for works registered in your local library.

## Start with a title or creator

1. In Library, press `Ctrl+F` to focus the search box.
2. Enter a work title or creator name. Search also uses saved information such as original and alternate titles, product IDs, providers, categories, formats, and collections.
3. If you have too many results, add a creator, category, or site filter.

## Combine creator and category filters

1. Select **Creator A** and **Creator B** in the creator filter. Either selection can match within that filter (OR).
2. Select **Manga** in the category filter. Results must satisfy both filter types (AND). In this example, a work must be manga by Creator A or Creator B.
3. Add a site or collection condition if you want to narrow the results further.

## If you cannot find a work

- **Is the work registered?** Check that the work is in your library and try the title or creator spelling saved there. Search covers saved library information. File contents and provider catalogs are outside that scope.
- **How do I remove filters?** Click an active-condition chip to remove it. Use `Clear all creators` or its equivalent to clear one filter type. `Clear all` resets the search and filters while keeping your sort order.

DLM Desktop runs on Windows x64. Local use is free and requires no DLM account. [Latest stable release](https://github.com/Ertelun/dlm-desktop/releases/latest) · [Known limitations](../KNOWN_LIMITATIONS.md)
