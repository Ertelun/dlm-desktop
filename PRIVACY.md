# Privacy — DLM Desktop 1.3.2（r213）

DLM Desktop is designed around local library use. Core local use does not require a mandatory DLM account, payment, or subscription.

Local viewing of registered works does not require a store/browser connection. Site-assisted acquisition, metadata/thumbnail retrieval, and provider pages use network connections to the relevant services. Provider pages may use their own cookies and browser storage; sign-in is performed by the user on those pages. Provider privacy policies apply to interactions with their sites.

Membership/fan-site intake groups files explicitly saved from one selected post. This release does not offer creator-post crawling or background synchronization.

Normal support should request only the minimum information needed to reproduce a problem. Do not post passwords, cookies/tokens, browser profiles, full library databases, purchased payloads, account identifiers, or unnecessary sensitive local paths in public Issues.

For sensitive security reports, use [GitHub Private Vulnerability Reporting](https://github.com/Ertelun/dlm-desktop/security/advisories/new). See [SECURITY.md](SECURITY.md).

These statements describe DLM's supported flows; they do not claim that credential-like data can never exist in browser/provider systems.
