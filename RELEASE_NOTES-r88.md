# DLM Desktop Public Beta — r88 (Windows x64)

DLM Desktopは、手元の同人・デジタル作品をWindows PC上で整理・閲覧するローカル中心のライブラリです。

このPublic Betaには、登録済みローカルライブラリの整理/閲覧、DLMユーザー状態のBackup / Restore、DLsite・DMM/FANZAの対応する通常ダウンロード向け取り込み支援が含まれます。

**r88では、任意の手元フォルダを新規作品としてLibrary登録する standalone Manual Local Intake は提供しません。**
一部の既存Provider-handoff画面ではローカルフォルダを選択・検証できますが、その操作だけで新規ローカル作品のpromotion/Library登録を完了するものではありません。

サービスへのログインと公式Download操作はユーザー自身が公式ページ上で行います。閲覧専用・公式プレイヤー専用・DRM管理など対象外の配信方式は、各サービスの公式手段をご利用ください。

このPublic Betaはコード署名されていません。WindowsでUnknown PublisherまたはMicrosoft Defender SmartScreenの警告が表示される場合があります。

公式Ertelun GitHub Releaseから取得したことと、公開SHA-256の一致を確認したうえで実行可否をご判断ください。

## Provider boundary

DLM Desktop supports qualified ordinary-download flows for DLsite and DMM/FANZA. Login and the official Download action remain user-operated.

Protected, viewer-only, official-player-only, DRM-controlled, and otherwise unsupported delivery modes remain on the provider's official route.

DLM Desktop is an independent application by Ertelun and is not an official application of, or endorsed by, DLsite or DMM/FANZA.
